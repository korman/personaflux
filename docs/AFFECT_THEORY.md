# 情感理论基础

## PAD 模型

PAD 是三维连续情绪模型，通常与 Albert Mehrabian 和 James A. Russell 的相关研究联系在一起：

- `Pleasure`：不愉快到愉快。
- `Arousal`：平静、低活跃到兴奋、高活跃。
- `Dominance`：顺从、无力到掌控、强势。

内部范围使用 `[-1, 1]` 还是 `[-100, 100]` 尚待行为规格决定。公开 ABI 不应在决策前冻结单位。

## 八种气质映射

PAD 三轴正负组合可映射为：

| P | A | D | 常见名称 |
|---:|---:|---:|---|
| + | + | + | Exuberant |
| + | + | - | Dependent |
| + | - | + | Relaxed |
| + | - | - | Docile |
| - | + | + | Hostile |
| - | + | - | Anxious |
| - | - | + | Disdainful |
| - | - | - | Bored |

PersonaFlux 可支持该映射，但不把名称硬编码为唯一解释。更通用的方式是配置 PAD 空间中的命名区域，并为重叠区域定义稳定优先级。

## 认知评价式规则

事件不直接决定情绪。角色根据自身立场解释事件：是否相信来源、如何看待目标、行为是否符合人格、当前唤醒程度、力量差和是否反复经历类似行为。

这种方向与认知评价理论相近，但除非明确实现并验证 OCC 等公开模型，不应宣称采用某个完整理论。PersonaFlux 初期采用自行定义、可测试的认知评价式规则。

## 状态分离

- `Pad`：当前情绪，可能随时间回归。
- `Relationship`：对对象的长期有向态度。
- `PersonalityTraits`：相对稳定的倾向。
- `Memory`：知道或相信的事件。
- `WellBeing`：可选长期累计指标，不属于标准 PAD 第四轴。

短期情绪、长期关系和人格不能压成同一个数值。

## 游戏化扩展

阵营继承、亲和度、短长期记忆、传闻可信度、习惯化、重要性阈值和力量差修正不是 PAD 理论本身，应作为 PersonaFlux 自己的可配置产品规则。
